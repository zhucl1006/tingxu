## 1. 需求分析与验收标准

### 验收标准（AC）
- **AC-01**：大模型 API Key 仅存在于网关环境变量中，客户端完全无感知；
- **AC-02**：DeepSeek 接口模拟超时（$> 15s$）或发生 429 限流时，网关在 1 秒内无缝切至 Qwen-2.5，客户端正常收到纪要；
- **AC-03**：服务端日志、监控链路中严禁出现任何请求体中的会议正文；
- **AC-04**：输出严格遵循 JSON Schema 结构，包含明确的证据段引用。
