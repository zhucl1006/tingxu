**最后更新：** 2026-10-30

**负责人：** 底层系统与音频研发组  
**目标：** 实现跨平台免驱动物理双轨音频录制：Windows 调用 WASAPI Loopback，macOS 调用 ScreenCaptureKit；麦克风（我方）与系统扬声器（对方）通道物理隔离；支持 16kHz 重采样与原子落盘。  
**架构摘要：** 利用 Rust `windows-rs` 与 macOS CoreAudio / ScreenCaptureKit C-FFI 绑定；构建无锁无 GC 停顿的单声道 PCM 双通道环形缓冲（`RingBuffer`），以 2 秒为周期切片写入本地磁盘分块文件。  
**技术栈：** Rust, WASAPI Loopback, ScreenCaptureKit, C-FFI, rubato (重采样), crossbeam-channel

## 1. 需求分析与验收标准

### 验收标准（AC）
- **AC-01**：在无需安装任何虚拟声卡或第三方驱动的前提下，Windows 与 macOS 均能成功录制到系统扬声器声音与麦克风声音；
- **AC-02**：双轨通道明确区分：Track 1 标记为 `MIC`，Track 2 标记为 `SYSTEM`；
- **AC-03**：输出标准化为单声道 16kHz、16-bit 线性 PCM 格式，丢帧率 $< 0.1\%$；
- **AC-04**：进程被强制强杀（SIGKILL）后，已生成的音频切片校验和完整，重启后无坏道损毁。
