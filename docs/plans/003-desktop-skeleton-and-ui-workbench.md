## 1. 需求分析与验收标准

### 验收标准（AC）
- **AC-01**：启动应用后在 macOS / Windows 正常渲染主窗口，内存初始占用 $< 50\text{MB}$；
- **AC-02**：点击“最小化至悬浮条”能隐藏主界面并唤起无边框透明置顶小条，支持贴边吸附；
- **AC-03**：会中双栏工作台支持自适应折叠与展开，点击左侧证据按钮可触发事件定位；
- **AC-04**：所有按钮、输入框、卡片容器均严格按 `<page>-<section>-<type>-<purpose>` 标注唯一 `data-testid`。
